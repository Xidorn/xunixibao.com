01 / CELL STATE PREDICTION

Research question

Does the target population contain distinct states? Do treatment-associated changes reflect shifts in subpopulation proportions, within-cell expression, or both?

02 / CELL STATE PREDICTION

Input data

Cell expression or imaging data, sample annotations, controls and timing. Dynamic inference also requires longitudinal or time-series evidence suited to the study design.

03 / CELL STATE PREDICTION

Expected outputs

State representations, subgroup comparisons, candidate markers and trajectory hypotheses. Distances in an embedding are not equivalent to elapsed biological time.

04 / CELL STATE PREDICTION

Validation approach

Use independent samples, marker assays or functional experiments to test state interpretations and investigate batch effects and cellular composition changes.

Define the scope using the available data and validation conditions. Generalization to unseen cell types, perturbations or experimental systems requires separate evaluation.
